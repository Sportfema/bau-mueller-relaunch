# Autonomous Execution Guidelines

- **Autonomous Execution**: Work proactively and implement requested changes directly without stopping for manual approval on intermediate steps.
- **No Blocking Question Prompts**: Do not use the `ask_question` interactive modal unless critical user input is strictly required and cannot be answered with sensible defaults. Prefer direct execution or normal markdown text questions in chat.
- **Minimal Review Friction**: Execute tasks end-to-end, verify results, and report findings directly. Avoid unnecessary planning pauses when the task is clear.
